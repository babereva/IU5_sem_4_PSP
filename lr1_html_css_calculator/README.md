## Дополнительное задание на защите

На защите было предложено реализовать **подсветку активного пункта навигации** — чтобы текущая страница визуально выделялась в меню.

**Реализация** — в `style.css` добавлен класс `.nav-item.active`:

```css
.nav-item {
  text-decoration: none;
  font-weight: 700;
  color: #2044a1;
  padding: 8px 18px;
  border-radius: 15px;
}

.nav-item.active {
  background: #2044a1;
  color: #ffffff;
}

.nav-item:hover {
  color: #ffffff;
}
```

На каждой странице нужному пункту навигации вручную проставляется класс `active` в HTML:

```html
<nav class="navigation">
  <a href="general.html" class="nav-item">Главная</a>
  <a href="about.html" class="nav-item">Обо мне</a>
  <a href="calculator.html" class="nav-item active">Калькулятор</a>
</nav>
```

Таким образом пользователь всегда видит, на какой странице находится.
