## Цель работы

Расширить приложение из ЛР3 — добавить **страницу аналитики** с реализацией алгоритмов обработки данных на JavaScript, а также интегрировать интерактивную **3D-визуализацию** с использованием библиотеки **Three.js**.


## Задание

На основе приложения из ЛР3 реализовать:

- алгоритмы анализа данных по карточкам товаров (подсчёт повторяющихся категорий, среднее значение, максимальная последовательность);
- загрузку и отображение 3D-модели персонажа в формате `.glb` с использованием Three.js и GLTFLoader;
- навигацию на страницу аналитики из шапки сайта.
