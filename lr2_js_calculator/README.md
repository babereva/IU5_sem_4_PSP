## Дополнительное задание на защите

На защите было предложено добавить **тематическую кнопку 🍼**, которая делит введённое число на 6 — количество кормлений в день для грудного ребёнка, тем самым рассчитывая объём одной порции.

**Реализация** — кнопка в `calculator.html`:

```html
<button id="btn_op_portion" class="my-btn secondary">🍼</button>
```

**Логика** в `script.js`:

```js
document.getElementById("btn_op_portion").onclick = function() {
  if (a === '') return
  const portion = (+a) / 6
  a = portion.toString()
  updateDisplay(parseFloat(portion.toFixed(5)).toString() + ' мл')
}
```

При нажатии кнопки текущее значение делится на 6 и к результату добавляется единица измерения «мл». Это делает калькулятор тематически связанным с вариантом задания — молочной кухней для детей.
